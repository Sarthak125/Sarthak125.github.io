# sarthak125.github.io

Root of https://sarthak125.github.io/. It only exists so Android can confirm that the Pit Wall app belongs to this site
(`.well-known/assetlinks.json`), which lets the app open full screen without an address bar. `.nojekyll` makes GitHub Pages serve the
`.well-known` folder. The home page forwards to Pit Wall: https://sarthak125.github.io/Pit-wall/
